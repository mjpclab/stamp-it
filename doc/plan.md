# 邮票化小程序

创建一个基于Web的邮票生成程序，输入为一张普通照片（见@img/input.png），输出为邮票样式（见@img/output.png）。

## 决定输出的尺寸

在界面上供用户输入：

- 孔直径，默认6px
- 孔间距，默认2px

- 水平齿孔数：以单个孔直径+孔间距为单位，设置水平重复数量，由于邮票边角为四分之一孔，因此水平起始位置为半个孔
- 垂直齿孔数：以单个孔直径+孔间距为单位，设置垂直重复数量，由于邮票边角为四分之一孔，因此垂直起始位置为半个孔

- 外边距背景色：默认为黑色，用于看清邮票的齿孔，@img/output.png的黑色内边框（邮票边缘外部）即为外边缘背景色
- 外边距透明度：范围0-1
- 内边距背景色：内边缘颜色，@img/output.png的金色内边框（属于邮票部分）即为内边缘背景色

## 自动计算的尺寸

邮票边缘的定义：邮票实际可见部分所属的矩形，像@img/01.gif那样

- 外边距：半个孔直径，但实际可见部分还包括打孔以后边缘向内凹陷的部分
- 内边距：孔直径+孔间距

## 导出功能

需要可以导出带透明/半透明的图像（如果外边距透明度不为1的话），格式为png。

## 技术选型

- Canvas 2D
- Canvas Web GPU
- SVG

# 邮票化小程序

创建一个基于Web的邮票生成程序，输入为一张普通照片（见@img/input.png），输出为邮票样式（见@img/output.png）。

## 决定输出的尺寸

在界面上供用户输入：

- 孔直径，默认8px
- 孔间距，默认4px

- 水平齿孔数：以单个孔直径+孔间距为单位，设置水平重复数量，由于邮票边角为四分之一孔，因此水平起始位置为半个孔
- 垂直齿孔数：以单个孔直径+孔间距为单位，设置垂直重复数量，由于邮票边角为四分之一孔，因此垂直起始位置为半个孔

- 外边距背景色：默认为黑色，用于看清邮票的齿孔，@img/output.png的黑色内边框（邮票边缘外部）即为外边缘背景色
- 外边距透明度：范围0-1
- 内边距背景色：内边缘颜色，@img/output.png的金色内边框（属于邮票部分）即为内边缘背景色

## 自动计算的尺寸

邮票边缘的定义：邮票实际可见部分所属的矩形，像@img/01.gif那样

- 外边距：半个孔直径，但实际可见部分还包括打孔以后边缘向内凹陷的部分
- 内边距：孔直径+孔间距
- 水平齿孔数/垂直齿孔数：齿孔数决定了实际画布大小，用户可以在UI上调整。但当用户选择一张图片后，自动重新计算齿孔数：内边缘以内是实际显示邮票图像的部分，图片按向上最小缩放、保持比例、仅一个方向发生裁剪（类似CSS的object-fit:cover）的尺寸大小，作为内容区域大小。有了内容区域大小，再根据内边距反推出水平齿孔数/垂直齿孔数。

## 导出功能

之前外边距的背景色就是整张邮票的底色了，但为了支持小型张，外边距也可以选择颜色、图片，导致外边距和邮票之间的打孔消失，现在需要再增加一个最底层的底色和透明度。这样在小型张边缘打孔位置应该可以看到完整的孔洞镂空，露出底色。外边距透明度默认改成0，以方便非小型张的情况下看到底色。

现在让我们来实现小全张/小版张功能。其实就是把单张邮票做矩阵排列，用户可以指定x列y行邮票组成的矩阵，并按顺序重复显示用户提供的图片。此处需要引入图片多选、拖放多长图片的功能。如果是2x2的矩阵，如果用户拖入1张图片，则重复这张图片，自然就变成2x2的小版张。如果用户拖入4张不同的图片，就形成了小全张。特例情况如：用户选了3张图，则按顺序重复即可，即1、2、3、1共4张。矩阵邮票紧挨在一起，应可以看到中间分割的孔洞露出的底色。内边距的渐变色应该应用于整个矩阵而不是单张邮票。
