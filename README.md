## 使用

直接用浏览器打开 `index.html` 即可，纯前端，无需服务端。

## 安装到本地（PWA）

通过 `https://` 访问时可以安装成本地应用，装好后离线也能用：

- **桌面 Chrome / Edge**：地址栏右侧的安装图标，或菜单 →「安装 邮票化」
- **Android Chrome**：菜单 →「安装应用」
- **iOS Safari**：分享 →「添加到主屏幕」

已安装的版本会在联网时自动跟进最新代码，无需手动更新。

> 用 `file://` 直接打开时功能完全正常，只是浏览器不允许安装。
